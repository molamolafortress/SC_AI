읽는 법:
- ZZZKBot은 너무 약해 변별력이 없다. 원본 McRave 미러전이 실제 기준이고, fixed 합계 3/6은 미러전 기대치(50%)와 맞는다. 3게임 단위 결과(0/3, 3/3)는 분산이다. **30게임 미만으로는 아무 결론도 내지 않는다.**
- 진영 편향은 확인되지 않았다(교대 실행 3/3). 앞으로 모든 실행은 `--alternate-sides`.
- LLM 전략은 미러전에서 호출 23회/게임, 0.75달러/게임, flip-flop 2회/게임. 30초 안전 주기 호출이 대부분이라 비용과 흔들림의 원인이다. 다음 조정: 안전 주기 60~90초, `keep_current_plan` 시 비용이 낮은 effort, 변경에 최소 유지 시간 적용.
- 게임 시간: 미러전 약 15분(21k 프레임)이 벽시계 2~6분. 4코어에서 3게임 병렬.
